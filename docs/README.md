# docs/

La documentación oficial de ms-clp-blp vive en [`confluence/`](confluence/): está declarada en
[`confluence/confluence-manifest.yml`](confluence/confluence-manifest.yml), escrita en español,
organizada por funcionalidad y se publica en Confluence con `scripts/publish_confluence.sh`
(reglas en `.claude/skills/confluence-docs/SKILL.md`).

El espacio de Confluence de este servicio **aún no existe**: su clave es el marcador
`TODO_CLP_BLP_SPACE` hasta que se cree.

Cualquier otro archivo en esta carpeta (análisis, planes de migración, comparativas) **no** es
documentación oficial y debe decirlo en su primera línea.
