#   .venv-confluence/bin/pip install -r scripts/requirements.txt
#
# Mínimos, no versiones exactas: el publicador usa APIs estables de las tres y no hay
# necesidad de reproducibilidad byte a byte para generar documentación.

# Convierte el Markdown de cada página a HTML antes de pasarlo a storage format.
